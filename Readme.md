# 🚀 **Nirikshan SahAI**  
### **AI-Driven Inspection System for Educational Institutes**  

A comprehensive and user-friendly AI-powered system designed to **automate and streamline the inspection process of educational institutes across India**.  

---

## 📌 **Overview**  
Traditional inspection processes suffer from:  
- 📊 **Manual data collection**  
- ❌ **Inconsistent results**  
- 🕑 **Time-consuming workflows**  
- 🔒 **Lack of transparency**  

**Nirikshan SahAI** addresses these challenges through **automation, AI-based verification, and insightful analytics**, ensuring **efficiency, accuracy, and transparency** in every inspection.

---

## 🛠️ **Core Technologies**  

- **📝 Document Analysis:** TAPAS (LLM), OCR (Optical Character Recognition)  
- **📷 Image Inspection:** YOLOv8, Custom CNN Models  
- **📊 Anomaly Detection:** Isolation Forest  
- **📈 Insights & Reporting:** GenAI for actionable intelligence  
- **🌍 Region Mapping:** Data-driven institutional visualization  

---

## 📊 **Key Features**  

✅ **Automated Document & Image Verification:**  
Advanced AI tools ensure compliance with regulatory norms.  

✅ **Real-Time Data Analysis & Insights:**  
Quick, data-backed decisions with intuitive dashboards.  

✅ **AI-Powered Infrastructure Inspection:**  
Classifications for washrooms, stamps, and other infrastructure assets using YOLOv8 and CNNs.  

✅ **Anomaly Detection:**  
Identify irregularities in statistical data with Isolation Forest models.  

✅ **Actionable Reports:**  
Comprehensive compliance, deficiency, and prediction reports.  

✅ **Region-Wise Mapping:**  
Visualize institution data with regional insights and unbiased scoring rubrics.  

✅ **Role-Based Access Control:**  
Tailored dashboards for inspectors, admins, and institutes.  

✅ **Fraud Detection Mechanisms:**  
Ensure transparency and detect anomalies in submissions.  

---

## 🖥️ **System Workflow**  
1. 📝 **Document Upload & Analysis:** Validate compliance with AI models.  
2. 📷 **Image Inspection:** Analyze infrastructure data using CNN & YOLOv8.  
3. 📊 **Anomaly Detection:** Spot statistical irregularities in submitted data.  
4. 🗂️ **Automated Report Generation:** Generate compliance and deficiency reports.  
5. 🌍 **Region-Based Visualization:** Display mapped data for institutional insights.  
6. 📑 **Actionable Feedback:** Provide actionable suggestions for improvement.
