## Nirikshan SahAI
- AI Driven Inspection System: A comprehensive, user-friendly system that automates the inspection process of educational institutes across India.
It addresses inefficiencies in traditional inspection processes, such as manual data collection, inconsistent results, and lack of transparency. By automating document and image verification using advanced AI tools, it ensures accuracy and saves time for inspectors and institutions alike.

The system employs LLMs such as TAPAS and ML techniques like OCR for document analysis, ensuring compliance with formats and regulatory norms. For infrastructure inspection, YOLOv8 and custom CNN models analyze images, including specific classifications such as washrooms and stamps. Anomaly detection through Isolation Forest adds an extra layer of insight by identifying irregularities in statistical data.

With features like real-time data analysis, automated report generation, and actionable insights via GenAI, Nirikshan SahAI provides comprehensive compliance, deficiency, and prediction reports. The project also includes region-wise mapping of institutions, unbiased ratings through rubrics, and fraud detection mechanisms, making it a versatile tool for inspectors, admins, and institutions.

By integrating intuitive dashboards with role-based access, the system simplifies inspection processes, reduces manual workloads, and enhances transparency. Its use of government datasets and feedback loops ensures accuracy, while its user-friendly interface enables seamless operations for all stakeholders involved in institutional inspections.
